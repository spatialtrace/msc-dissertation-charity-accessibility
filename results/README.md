# Results included in this repository

`summary/` contains final aggregate tables used to check the dissertation narrative. `qa/` contains method manifests, conservation checks, execution audits and SHA-256 input/output records.

The included values are calculated from full-precision analytical files. Reader-facing percentages and percentage-point changes can be rounded to one decimal place, but the CSV files preserve the available execution precision.

LSOA-level results and licensed spatial files are intentionally excluded; see [`../DATA_AVAILABILITY.md`](../DATA_AVAILABILITY.md).
