# Step 4 — HP–LA and trajectories

Annual High Pressure–Low Accessibility status is defined with strict inequalities:

- Care50 rate above the annual median; and
- A* below the annual median.

The three annual binary statuses are mapped to Persistent HP–LA, Emerging HP–LA, Resolved/improved, Intermittent and Never HP–LA trajectories. ICB and fixed-2021 urban–rural outputs are descriptive decompositions of these frozen LSOA results.

Run `python run_workflow.py` for the core annual/trajectory workflow. Run
`icb_urban_rural_decomposition.ipynb` when the ICB and urban–rural decomposition
is also required.
