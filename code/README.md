# Annotated analysis code

The numbered directories follow the final dissertation workflow. Each notebook contains Markdown sections for analytical decisions, inputs, calculations, hand-offs, QA and interpretation limits.

Set `DISSERTATION_DATA_ROOT` before running. Machine-specific absolute paths, raw data, licensed road files, caches, generated figures and LSOA-level outputs are not committed.

The source configurations retain the final method parameters. Historical Bi-LISA, regression, BYM2 and mismatch-index code is not part of this package.
